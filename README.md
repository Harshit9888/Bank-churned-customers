# Bank Customer Churn Analysis – Business Analyst Portfolio Project

## Project Overview
This simulated project analyzes customer churn patterns and identifies high-risk customer segments to support targeted retention strategies.

## My Role
Business Analyst — requirements gathering, BRD preparation, user-story writing, acceptance criteria, and Jira backlog organization.

## Tools Used
- Jira — Epic, user stories, acceptance criteria, backlog, and workflow
- SQL/Excel/Tableau — data analysis and reporting
- Microsoft Word/Google Docs — BRD documentation

 ## Key Outcome
Created a structured requirements and delivery workflow for a customer-churn dashboard that helps stakeholders understand high-risk customer segments.
